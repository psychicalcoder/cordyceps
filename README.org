#+TITLE: Cordyceps: Named Parameters for Emacs Lisp with zero runtime overhead

The connascence of position (CoP) in function arguments is a serious problem that ruins the readability of Lisp code. /cl-libs/ provides ~cl-defun~ with ~&keywords~ allows developers to define functions called with keyword arguments, such as ~(cl-remove-if pred seq :key #'car)~. However, each time we call the function, the keyword arguments are parsed. It is usually not necessary since the keywords and the value expression are usually known at compile time. Coryceps provides similar keywords arguments but the keywords are parsed when compilation.

** Usage

#+BEGIN_SRC emacs-lisp
  (eval-when-compile
    (require 'cordyceps))

  (np-defun my-function ((arg1 defval1) arg2 (arg3 defval3))
    "Docs"
    (if (and arg1 arg2)
        arg3
      nil))

  (my-function :arg2 t :arg1 (list 1 2))
#+END_SRC
